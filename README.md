#URL Shortener
## Descriprion
I wanted to practice more with Go. The backend is written entirely in Go. I chose PostgreSQL as the database because I find it more comfortable to work with, and it is widely used in real-world projects.


## Technologies used:
* ### PostgreSQL
* ### Golang

## Packages used:
* ### net/http — for handling HTTP requests.
* ### html/template — for rendering the UI.
* ### database/sql — for database interactions.
* ### github.com/lib/pq — PostgreSQL driver for Go.

## Files:
* ### main.go
* ### server.go
* ### short.go
* ### storage.go
